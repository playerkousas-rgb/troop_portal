## 2. 大項未做（排序＝BUILD §10 施工次序）

### ① 旅 `Code.gs`（P0 後端）—— 最大一件
- `doGet`/`doPost` 首行 `requireAuth`；**key 未設定＝拒絕敏感 action**（fail closed）
- **`sig` 驗簽**：`HMAC-SHA256(action+ts+nonce+sha256(body))`、±5 分鐘、nonce 一次性（CacheService 10 分鐘）、雙通道（query 防 GAS 302／body）
- **action 白名單**（讀 12／寫 19）＋永不接受清單；`setGate`／`upsertUser`／`bulkAddUsers`／`exportAll`…
- **ScriptLock `waitLock(20s)`**、原子寫（暫存行＋swap）、逐表寫自證（寫完讀返）
- `AUDIT_LOG`（`prev_hash` 鏈）／`ACCESS_LOG`（append-only、server-side）
- `dbInfo`／`status`（`backendVersion`）、`exportAll`／`importAll`、Drive 備份＋每週排程
- 生成物唔 commit：`scripts/build-gas.mjs` 產生 `apps-script/Code.gs`

### ② `/api/*`（Vercel functions，零依賴）
- `/api/proxy`：驗 session → 注入 apikey → 打旅 `/exec`
- `/api/auth`（登入／登出／改密碼）、`/api/super`（**固定受信端點回打驗票**：60 秒票據、AES-GCM、一次性防重放）
- `/api/units`、`/api/downstreams`、cache 5 分鐘＋flush endpoint
- Session：JWT HttpOnly `Secure; SameSite=Lax`、≤30 分鐘＋silent refresh

### ③ 真密碼與安全
- PBKDF2-SHA256 ≥100k＋per-user salt＋timing-safe compare；舊 hash 首登自動升級
- 每帳號 5 次失敗鎖 15 分鐘；`mustChangePw` 期間只放行改密碼 API；改密碼 `pv+1`
- 忘記密碼（email 一次性連結）、邀請連結（12 字元、24 小時）
- 秘密掃描測試（掃死後門／舊 hash）

### ④ 真 `sig` 接駁
- 旅側落碼後，用 **`vsbadge`／`roverbadge`（已 built）** 做首個實測：登記 → 測試連線 → 開戶 → 搬數 → 閂口
- 其他團照 §4.8 清單補（`handleSignedRequest`／`DOWNSTREAM_*`／`ALLOW_LOCAL_LOGIN`／`SUPER_VERIFY_URL`／守護測試）
- **閂口次序鐵律**（升級 MD §12④）：**先搬數、先測連線，先至閂口**；而且「未起好進度 sig 路徑之前唔好閂口」

### ⑤ 同步與多人寫入
- 版本由 server 派（ISO＋隨機尾數）、寫入帶 `baseVersion` 樂觀鎖、撞版回 `conflict:true`
- merge3 欄位級合併（同格衝突逐格確認）；ScriptLock busy → 前端排隊重試（backoff＋jitter）
- 大庫分件（`saveDbPart`）＋分段讀；刪除＝tombstone，後端定期 purge

### ⑥ 個人化訂閱 ★（BUILD 寫「重中之重」）
- 前端訂閱設定 → **圖書館現有推送鏈**（Supabase `push_subscriptions` → GitHub Actions 06:00 `notify.py` → pywebpush）
- 要圖書館側改：`require_same_origin` 加 origin allowlist；`push_subscriptions` 加 `source` 欄
- 通告頁＝本單位通告＋已訂閱圖書館通告（同頁同列表、來源標示）

### ⑦ 平台與教材
- ADMIN 收件匣 GAS（只服務獨立前端接入、per-IP 限流、2FA）＋ units.json／Vercel env 流程
- 教材三層（角色快速入門／模組說明／MOCK 引導任務）＋「開旅 checklist」

### ⑧ 未做嘅功能模組（UI 已有目錄／部分）
- **相簿**：上載（單檔 ≤5MB、每筆 3 張、每日上限）、公開發佈要家長同意確認 —— 用戶已定案**今輪唔開**
- 進度頁（B 模式打進度 `/exec`）—— 屬支部系統；旅側只留接入位
- 財務／物資「真提交」（支部用自己 key 簽）—— 目前旅側有 UI 同示範流程
