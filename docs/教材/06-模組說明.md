# 模組說明（跟模組註冊表）

> UI 版本：**系統 → 教學 → 模組說明**（同一份內容，畫面好睇啲）。模組開關由旅長控制；**閂咗＝隱藏，唔會刪資料**。

| 模組 | 一句講 | 主要角色 | 快取新鮮度 |
|---|---|---|---|
| 我嘅支部 | 你嘅支部一頁過：成員／活動／物資／通告 | 支部人員 | 5 分鐘（通告／活動） |
| 通告 | 發佈、分享俾指定支部、公開頁報名、訂閱 | 旅長／教練員／支部執委 | 5 分鐘 |
| 行事曆 | 支部／旅活動；可訂閱 feed、分享單一活動 | 同上 | 5 分鐘 |
| 財務 | 支部提交 → 旅確認；獨立 tab | 支部財務 ＋ 旅長 | 30 分鐘 |
| 物資 | 借用／歸還／庫存；跨支部共享範圍 | 支部物資 ＋ 旅長 | 30 分鐘 |
| 移交／升降團 | 成員由 A 團去 B 團（B 團接收） | 兩邊領袖 | 即時（唔 cache） |
| 待辦與批核 | 開戶申請／財務／移交／求救集中一頁 | 旅長／教練員 | 即時 |
| 分享中心 | 接收／退回其他支部分享（只有通告＋活動） | 支部執委或以上 | 5 分鐘 |
| 用戶與身份 | 帳號、身份、職稱、權限、邀請 | 旅長 | 即時 |
| 支部與接駁 | 登記下游／測試連線／閂閘／燈號 | 旅長 | 5 分鐘 |
| 系統 | 模組開關、審計、匯出匯入、備份、診斷 | 旅長 | 即時 |
| 平台 | 接入收件匣、units、金鑰輪換（超管） | 超管 | 即時 |
| 教學 | 你而家睇緊嘅嘢 | 全部 | 跟版本 |

## 規矩

- **一個掣寫入**：所有改動先落本機（🟡），撳「儲存到後端」才真寫；寫完會**讀返自證**（`confirmed:true` 先算成功）。
- **撞版唔會自動覆蓋**：同一格兩邊都改過 → 彈出嚟逐格揀（批量／無人看場才 serverTime 新者勝，並留低紀錄）。
- **刪除＝墓碑**：刪咗嘅行會留紀錄 90 日（邊個、幾時、為咩），唔會靜靜消失。
