# 平台超管（隱藏）· 快速入門

> 你**唔係旅長**：你係開旅、接入、輪換、救火嘅人。日常旅務一律用旅長戶做。

## 入口（唔會喺任何名單出現）

`index.html?step=super`，或者旅閘右上 ⚜ 撳五下 → 用平台密鑰（`SUPER_KEY`）入。

## 四件事

1. **開旅**：申請 → 核對 → `data/units.json` 加一條 ＋ Vercel env（`TROOP_<旅ID>_BACKEND`／`_APIKEY`）→ Redeploy → 通知申請人。
2. **接入下游**：確認對方 deploy 好、`/exec` 通（用「測試連線」）、KEY 對得上；**登記後叫對方 rotate key 一次**。
3. **輪換**：APIKEY 過期／外洩 → 輪換 → 更新 Vercel env → Redeploy。
4. **救火（第二層備援）**：旅側全死（旅長入唔到／閂錯閘）→ 你可以入任何支部／任何模組，做「開返閘 ＋ 重設旅長密碼」。

## 每次入去都會見到

紅色橫額（提醒你係超管、每個動作都會入審計）。**唔好喺度做旅務** —— 會分唔清係邊個決定。

## 我而家應該做咩

- 收到接入申請 → 先 ping／status，過得去先加 env。
- 有團長求救且旅側確認處理唔到 → 你出手，做完記低（審計會自動記）。
