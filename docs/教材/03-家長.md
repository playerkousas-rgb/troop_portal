# 家長（監護人）· 快速入門

> 你睇嘅係**你子女嘅事**：唔係全旅、唔係成個支部。

## 五分鐘

1. 入閘 → 揀你子女所屬嘅團 → 「家長（監護人）」→ 打密碼。
2. 首次登入：**要該團領袖確認**之後先睇到子女資料（防止亂綁）。
3. 你會見到：我的子女（跨支部，如果你有兩個仔女喺唔同團）／通告（含子女所屬支部）／行事曆／繳費／公開頁報名。
4. 你可以：幫子女報名／請假、睇出席、收通告（訂閱）、去公開頁（免登入）。

## 私隱

- 你只會睇到你**已綁定**嘅子女；其他團員嘅資料唔會出現。
- 你嘅聯絡資料只俾**該團領袖**同旅部，用嚟聯絡你（唔會公開、唔會賣）。
- 想解除綁定／刪帳號：搵該團領袖（旅系統有紀錄，刪帳號亦保至少一個領袖戶）。

## 我而家應該做咩

- 睇唔到子女？多數係領袖未確認：請佢喺「待辦與批核 → 開戶申請／家長綁定」撳批。
- 收唔到通告？去「通告 → 我嘅訂閱」睇你訂咗邊啲題材（訂閱存本機，唔會經 server）。
