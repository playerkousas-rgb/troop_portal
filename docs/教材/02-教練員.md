# 教練員 · 快速入門

> 你係旅嘅第二把手：**只做獲授權嘅支部**，唔會見到全旅所有資料。

## 五分鐘

1. 入閘 → 「旅長／教練員」→ 打密碼；頂欄會顯示你嘅角色同權限範圍。
2. **睇邊個支部授權咗你**：旅長 → 用戶與身份 → 權限總表 → 你嘅名。
3. 你**做得到**：睇支部、發通告／活動、審財務摘要、睇物資、處理求救、批核（如果旅長授咗）。
4. 你**做唔到**（要旅長）：改模組開關、刪帳號、閂／開支部登入通道、輪換金鑰、匯出／匯入全庫。

## 規矩

- 你寫入嘅每一筆都會入審計（`actor` ＝ 你），唔會算落旅長度。
- 跨支部（想入未授權嘅團）：要旅長加 `branch_access`，或者由該團自己開戶。
- 權限**封頂**：你唔可以授人一啲你自己都冇嘅權限（例如系統層）。

## 我而家應該做咩

- 想幫某一團？搵旅長加 `branch_access`（有紀錄）。
- 見到 🔴？**唔好狂撳**：睇診斷，通常係 session 過期（重新登入）或者 env 未設好（搵 ADMIN）。
