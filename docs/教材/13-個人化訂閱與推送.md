# 個人化訂閱與推送（旅長／ADMIN 開通用）

> 五分鐘睇完。規矩：**推送基建復用圖書館現有鏈，旅系統只做「訂閱設定前端」。**
> 呢篇講你而家應該做咩（開通步驟）、點解要咁樣設計、同埋出咗事點查。

## 一、交付邊樣嘢（責任線）

| 邊個 | 負責 |
|---|---|
| **旅系統（本 repo）** | 訂閱 UI（支部／分類）、service worker（`sw.js` 收推送）、真訂閱四步（能力→設定→權限→訂閱）、把訂閱**匿名轉發**去館方 |
| **圖書館（館方系統）** | Supabase `push_subscriptions`（儲訂閱）、每日 06:00 GitHub Actions `notify.py`、pywebpush 發送（VAPID 私鑰）、7 日 rolling 補漏 |
| **Vercel env（旅側）** | `VAPID_PUBLIC_KEY`（公開，前端訂閱要用）、`PUSH_INGEST_URL`（館方收件位）、`PUSH_INGEST_KEY`（可選 Bearer） |

> ⚠️ **旅側永遠唔存訂閱表**：`/api/push` 只係轉發閘（白名單剝 PII ＋ 限流）。
> 旅側亦冇 VAPID 私鑰 —— 發送權只喺館方。

## 二、開通步驟（ADMIN）

1. **館方側**：確認 `push_subscriptions` 表存在（欄位最少 `source`／`endpoint`／`keys`／`topics`／`scope`／`at`），
   同埋收件位（Supabase Edge Function 或現成 webhook）已部署、會回 2xx。
2. **Vercel env（旅側）**：
   ```
   VAPID_PUBLIC_KEY  = <館方 VAPID 公鑰，base64url>
   PUSH_INGEST_URL   = <館方收件位 URL>
   PUSH_INGEST_KEY   = <可選：收件位要嘅 Bearer>
   ```
3. 部署後打開旅系統 →「我嘅訂閱」→ 應該見到 **推送鏈：已開通**。
4. 用手機／桌面瀏覽器撳「開啟推送（呢部裝置）」：
   - 瀏覽器會問通知權限 → 要撳「允許」
   - 成功＝「已訂閱呢部裝置（館方鏈）」
5. **驗收**：叫館方（或者自己）喺 Supabase 見到新一筆訂閱（`source='troop_portal'`），
   再等一次每日推送，或者叫館方即刻發一個測試 push。

## 三、點解要咁樣設計（唔可以「自己整多一條鏈」）

- 一條鏈＝一個責任：多一條鏈＝多一份訂閱表、多一份私鑰、多一個地方會靜靜死咗冇人知。
- 館方要嘅係**館藏數據**：知「幾多人訂、訂咩題材、30 日活躍」就夠；
  **唔需要知邊個係邊個**。所以我哋送出嘅 payload 只有：
  `source`／`endpoint`／`keys`／`topics`／`scope`（例：`82/sc0082`）／`at`。
  **冇姓名、冇 email、冇 YMIS、冇電話**（`/api/push` 有白名單，就算前端唔小心加咗都會剝走）。
- 前端只認**同源** `/api/push`：Supabase URL／key 永遠唔會出現喺瀏覽器（唔會經 QR／URL 洩漏）。

## 四、出事點查（對症下藥）

| 症狀 | 大機會原因 | 做法 |
|---|---|---|
| 訂閱頁顯示「未開通：未設 VAPID_PUBLIC_KEY／PUSH_INGEST_URL」 | env 未設（或者未重新部署） | 補 env → redeploy → 重新整理頁面 |
| 撳「開啟推送」彈「未開通知權限」 | 用戶上次撳咗「封鎖」 | 瀏覽器設定 → 網站設定 → 通知 → 重設為「詢問」 |
| 彈「訂閱失敗」 | sw 註冊唔到（唔喺 https／localhost？）或者 VAPID 公鑰格式唔啱 | 檢查 https、檢查公鑰係 base64url 而唔係私鑰 |
| 訂閱成功但收唔到 | ①館方 notify.py 冇跑／發送失敗 ②訂閱過期（瀏覽器換過） ③焦點：iOS 要「加到主畫面」先收得 | 睇館方 send log；用戶重新撳一次「開啟推送」 |
| 通知撳落去冇反應 | sw 版本舊 | 用戶重新整理（或者登出再登入）令 sw 更新 |
| 每次開 APP 都叫「重新訂閱」 | 瀏覽器不停換訂閱（多數係私密瀏覽／清 cookie 設定） | 屬正常保護；提醒用戶唔好用私密模式 |

## 五、私隱同合規（PDPO）

- 訂閱係**匿名**：館方見到「一部裝置訂咗邊幾類通告」，見唔到「邊位童軍／家長」。
- 取消：用戶撳「關閉推送」＝旅側即刻停用本機設定 ＋通知館方移除；旅側冇任何副本要刪。
- 想連裝置都換：清瀏覽器資料／用第二個瀏覽器＝新 endpoint，舊嗰個由館方 rolling 清理。
- 審計：旅側只記「有人訂閱咗（匿名）」一件事（metadata only，冇 endpoint／冇 keys）。
