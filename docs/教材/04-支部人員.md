# 支部人員（團長／副團長／執委／隊長／團員）· 快速入門

> 旅＝你嘅登入窗口，但**你嘅世界係你個支部**（SHEET）。旅側只多咗「其他支部分享咗、而你哋接收咗」嘅嘢。

## 五分鐘

1. 入閘 → 揀**你嗰團** → 揀身份（執委／團隊長／隊長／團員…）→ 打密碼。
2. 入到去：我嘅支部／通告／行事曆／物資（睇你權限）。
3. **分享**：分享中心 → 見到「待接收」＝其他支部想同你哋分享（通告／活動）。**你接收咗先會出現喺你哋嘅頁**；退回要寫理由（留紀錄）。
4. **跨支部幫手**：要另一個支部嘅領袖同意（`branch_access`）。
5. **入唔到？** 撳 🆘 求救（免登入）—— 旅部會有人跟。

## 兩把閘（要知，唔使理）

- **支部系統登入通道**：旅長可以「閂閘」＝你哋唔可以由支部系統自己登入，出入只經旅閘。你只會見到效果（403 ＋ 求救連結），控制面**永遠喺旅側登記版面**。
- **唔會自動收嘢**：任何分享／申請都要有人（你哋執委或以上）撳「接收／批准」。

## 我而家應該做咩

- 18+ 同未夠 18 嘅身份分開，唔好用錯（影響可見範圍同同意要求）。
- 見到「唔夠權決定」：加註解交團長／執委，唔好自己硬嚟。
