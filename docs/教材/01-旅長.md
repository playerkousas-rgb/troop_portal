# 旅長 · 快速入門（首次登入必見）

> 你係旅系統最高權限（除平台超管）。**你唔係管支部日常** —— 你係開旅、接駁、批核、睇總數。

## 五分鐘做完呢五步

1. **入閘**：`index.html?step=unit` → 揀旅 → 「旅長／教練員」→ 打密碼（首登會強制改密碼）。
2. **睇三色燈**：頂欄 🟡＝有嘢未寫入後端（撳「儲存到後端」才會寫）／🔴＝寫入有問題／🟢＝同後端一致。
3. **支部與接駁**：旅長 → 支部 → 揀團 →「接駁與登記」→ 填下游 `/exec` ＋ 下游 APIKEY → **測試連線**（綠燈先算通）。
4. **邀人**：用戶與身份 → 邀請 → 揀角色（旅員／家長／支部人員）＋可揀「順便為下游開戶」（兩邊同一個 hash）。
5. **睇待辦**：待辦與批核 → 一次過睇齊開戶申請／財務提交／移交／求救。

## 你要知嘅鐵律

- **閂閘之前**：先確認接駁燈綠、測試連線成功、進度下游已登記（未達標會出警告，唔會硬擋，但出事你孭）。
- **刪帳號保至少 1 個**：刪／停用最後一個領袖戶會被擋（`keep_one`）。
- **超管唔係你**：超管（隱藏）做開旅／接入／輪換；旅務一律用你嘅旅長戶做，審計才分得清邊個做。
- **求救一定有人睇**：求救單會落旅 SHEET ＋ 送去 Scout Admin 收件匣；你嘅三個動作係「開返支部系統登入／重設密碼／答覆並結案」。

## 我而家應該做咩

- 睇唔到 🟢？去「系統 → 診斷」睇 `dbInfo`（分頁齊唔齊、審計鏈好唔好、BACKEND／APIKEY 有冇）。
- 有人話入唔到？去「待辦與批核 → 🆘 求救」，核實身份先做（打電話／WhatsApp 確認）。
