## 三條規矩

1. **教材同版本一齊走**：改咗功能就改呢度，唔好另開一份 wiki（出咗事一定係睇 repo 呢份）。
2. **示範＝沙盒**：唔想喺真 Sheet 試 → 用示範旅（`npm run dev`）亂撳；匯出嘅嘢帶 `_exportedFrom:'mock'`，唔會同真數據撈亂。
3. **每頁最後都有「我而家應該做咩」**：跟住做，做完應該見到咩 → 睇唔到就係有嘢未接好（去「系統 → 診斷」）。
