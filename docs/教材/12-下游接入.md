# 下游接入（團側 GAS 用）

> 三十行內接完。對象＝團側／支部側嘅 Apps Script 後端（vs_portal、cubs_portal、scout_portal、
> gh_portal、以及已 built 嘅 vsbadge／roverbadge）。抄範本檔：**`apps-script/Downstream.gs`**。

## 一、三條規矩（唔可以改）

1. **上游簽名進嚟**：`canonical = action \n ts \n nonce \n sha256(digest)`，
   HMAC-SHA256，密鑰＝`sha256(PURPOSE + '|' + 本機 API_KEY)`；±5 分鐘；
   nonce 一次性（cache 快路 ＋ 持久環，cache 蒸發都擋得住重放）。
2. **本機直接入口掣**：ScriptProperties `ALLOW_LOCAL_LOGIN`（未設定＝**開**；`'false'`＝閂）。
   閂咗之後只收上游簽名；**本地憑證操作**（login／apply／logout／改密碼…）永不經簽名接受 ——
   要登入就要真係驗密碼。閂咗口嘅回應要帶求救指引（見第四節）。
3. **下游永不回打上游**（唯一例外＝中央登入票據回打固定端點，嗰個係上游側設計，唔關下游事）。
   下游要知身份＝上游帶落嚟（`sub`＝SCOUT_ID）；下游要維持登入狀態＝**自己簽 leaf token**（第二節）。

## 二、leaf 自製 session token（BUILD §10 條 7）

下游驗完上游簽名之後，**自己簽一張短期 session token**。之後下游自己嘅 UI 請求帶呢張
token 就得：唔使每 request 驗上游 sig、唔使每 request 回打上游。

```
上游（帶有效 sig）→ action=leafLogin, sub=YMIS-2001, role=member, pv=3
下游             → { leaf_token: "<payload>.<hmac>" , ttlMs: 1800000 }
下游 UI          → 之後每個請求帶 leaf_token（HttpOnly cookie 最好）
```

- 內容：`{ sub, role, name, node, scope, pv, iat, exp }`（base64url ＋ hex HMAC）。
- 密鑰：下游自己嘅 `API_KEY` 派生（`PURPOSE|API_KEY|leaf-session-v1`）——**唔會同上游 sig 密鑰互用**。
- TTL：**5 分鐘 ~ 30 分鐘**（自動 clamp；叫佢發 10 年都只會得 30 分鐘）。
- 失效四路：① 到期 ② `pv` 唔同（改密碼即全體失效）③ `node` 唔對（token 搬去第二個 portal 用唔到）
  ④ 換 `API_KEY`（換 key 即所有舊 token 廢）。
- 驗證函式：`verifyLeafToken(token, { now, node, pv })`；請求入口用 `requireLeafToken(e, body)`。

> **點解唔用上游嘅 session？** 上游 JWT 綁旅側網域同 cookie；下游 GAS 係另一個 origin，
> 收唔到亦唔應該收到。下游自簽＝各自負責，責任清楚，亦是「中央登入獨一 + 本地 session」嘅正解。

## 三、抄落去（四步）

```js
/* ① 抄 apps-script/Downstream.gs 入你個 GAS；改 LINK_PURPOSE 同白名單 */
var LINK_PURPOSE = 'scportal-troop-sig-v1';        // ★ 每個 portal 唔同（旅側登記要一致）
var LINK_READ_ACTIONS  = ['load', 'getLinkState', ...];   // 你真係有嘅讀取
var LINK_WRITE_ACTIONS = ['save', 'addMember', ...];      // 你真係有嘅寫入

/* ② doPost 開頭加三行 */
function doPost(e) {
  var handled = linkHandlePost(e);
  if (handled) return handled;          // 已處理（sig 請求 或者 已閂口嘅本地請求）
  ...你自己原本嘅邏輯...
}

/* ③ handleSignedRequest() 裡面填你嘅讀寫（範本已放空殼） */
/* ④ 本機 ScriptProperties 設 API_KEY（唔設＝簽名驗唔到，直接拒） */
```

## 四、閂口之後：403 頁要點寫

`linkHandlePost` 已回一個標準形狀：

```json
{ "success": false, "local_login": false, "upstream_only": true,
  "code": "local_login_closed",
  "rescue": "（免登入）求救：請去旅系統登入頁撳「🆘 求救」…",
  "error": "本機直接入口已閂…請由旅入口入。" }
```

前端見到 `upstream_only:true` 就要顯示：**「請由旅入口登入」＋求救連結**，
唔可以只用一句「密碼錯誤」打死人（咁做會令人以為自己記錯密碼）。

## 五、自我檢查（貼完之後跑）

| 檢查 | 期望 |
|---|---|
| 冇簽名打 `login`（本地入口開） | 照舊行你原本嘅登入 |
| 冇簽名打 `login`（`ALLOW_LOCAL_LOGIN=false`） | `local_login_closed` ＋ 求救指引 |
| 有效簽名打 `getLinkState` | `success:true` |
| 同一張簽名打第二次 | `sig_replayed`（就算 cache 清咗都一樣） |
| 有效簽名打 `login`／`changePassword` | `never_accept` |
| 有效簽名打 `leafLogin` | 回 `leaf_token` |
| 用返 leaf token（閂口狀態） | 放行 |
| 改 leaf token 一個字／隔 31 分鐘再用 | `bad_token` / `token_expired` |
| 改密碼之後用舊 leaf token | `stale_pv` |

> 旅側「支部登記」有「測試連線」掣，會用真 sig 打你個 `getLinkState` ——
> 綠燈＝接入通。
