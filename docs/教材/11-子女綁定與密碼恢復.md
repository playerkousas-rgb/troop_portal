# 子女綁定與密碼恢復（家長／支部人員／旅長用）

> 五分鐘睇完。呢篇講兩件事：**① 家長點綁子女**（同埋為咩一定要領袖確認）；
> **② 唔記得密碼點算**（點樣攞一次性連結，寄唔到信點算）。

---

## 一、家長綁子女（四步）

| 步 | 邊個做 | 做咩 |
|---|---|---|
| ① 申請 | 家長 | 登入 →「我的子女」→ 入子女嘅 **YMIS／SCOUT_ID** → 送出綁定申請 |
| ② 待批 | 系統 | 申請入「待辦與批核 → 子女綁定」，狀態 `pending`。**呢個時候家長仲係睇唔到子女任何資料** |
| ③ 確認 | 該團領袖 | 核對名冊（同一個名？同一個編號？係咪監護人本人？）→ 撳「批准」或「拒絕（要寫原因）」 |
| ④ 見到 | 家長 | 一按批准，`children` 即刻寫落家長戶 → 下次入「我的子女」就見到進度、通告、繳費摘要 |

### 點解要領袖確認？（唔係多餘步驟）

一個編號就係一個真人。如果唔使確認，任何人打「YMIS-2011」就睇到人哋個仔嘅生日、
進度、繳費紀錄 —— 呢個係**認人仔**，唔係開戶。所以：

- 系統**只認名冊**：名冊搵唔到呢個 YMIS → 申請即時擋（`no_child`），唔會入待批；
- 名冊有、但要**領袖確認**先寫入 `children`；
- 確認只可以寫落**家長戶**，唔會動子女自己嗰個戶（小朋友唔會因為家長綁定而變咗身份）；
- 同一張申請**決定過就唔可以再決定**（防重放）；同一個人重複申請會自動去重（`duplicate`）。

### 領袖會見到咩

待辦列表會顯示：家長名、`YMIS`、名冊上嘅名、所屬支部。名冊對唔上會直接標
**⚠️ 名冊對唔上** —— 呢啲唔應該批，要人手查（可能係家長打錯字，或者成員未入名冊）。

### 常見問題

| 情況 | 處理 |
|---|---|
| 家長話「個仔升咗團，要唔要再綁？」 | **唔使**。綁定用全球 SCOUT_ID，升團／轉支部／調區都零改動 |
| 家長用第二個 email 申請 | 綁定係綁**家長戶**（email）。請用登記嗰個 email 登入再申請 |
| 想改／取消綁定 | 領袖側唔會「改」，只會處理新申請；要除名請由旅長人手處理（有審計紀錄） |
| 同一個子女兩個家長想睇 | 兩個家長戶各自申請、各自確認 —— 兩邊都寫得入（唔會互相覆蓋） |

## 二、唔記得密碼（一次性連結）

```
登入頁 →「唔記得密碼？」→ 入自己個 email → 系統寄一條連結
      → 撳入去（帶 token）→ 設新密碼 → 完成
```

- 連結**一次性**、**30 分鐘**有效（`setupExp`）。用完即廢，同一條連結再用會俾人拒（`bad_token`）。
- 過期冇所謂，重新申請一次就得。
- 密碼由**伺服器**雜湊（PBKDF2-SHA256 ≥100k＋每人 salt）。**GAS 同旅系統都見唔到你的明文密碼**。
- 為咗防止有人逐個 email 試「邊個有戶口」，系統**唔會**講「呢個 email 冇登記」——
  有冇戶口都係同一個回覆。所以打錯 email 你只會「收唔到信」，唔會有其他線索。

### 寄唔到信點算？（山旮旯、學校攔信、未設定連結網址）

GAS 某啲情況寄唔到（未設定 `APP_URL`，或者每日寄信配額用晒）。呢個時候系統**唔會扮寄咗**，
佢會回一張「**人手傳**」單：內容有一次性 token。

領袖做法：**當面或者經私密頻道**把 token 交俾本人 → 佢喺登入頁撳「唔記得密碼？」→
（或者直接開設定頁）→ 入 token ＋ 自己嘅 email → 設新密碼。

> ⚠️ Token 等於一次登入機會：唔好貼公開群組、唔好大聲讀出嚟、唔好經第三者轉手。

### 求救（最後一路）

如果連 email 都收唔到、又連絡唔到領袖：登入頁有 **🆘 求救** 掣（**免登入**）。
求救單只係**請求**，唔會自動開任何嘢 —— 旅側 ADMIN 收到會**人手核實身份**再處理
（開返登入／重設密碼／答覆結案）。

---

## 三、給支部人員／旅長：安全要點

1. **唔好幫人代設密碼**：除咗「求救 → 重設臨時密碼」呢條路（首登強制改），唔應該有人知你密碼。
2. **確認子女綁定前，最少核對兩樣**：名冊上嘅名 ＋ 家長身份（電話／當面）。
3. **名冊對唔上，唔好「照批住先」**：先叫該團加名冊，或者請家長確認編號。
4. 所有綁定／確認／拒絕都會入**操作紀錄**（誰、幾時、邊個編號、原因）—— 出事追得到。
