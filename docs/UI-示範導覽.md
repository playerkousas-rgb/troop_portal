# 旅系統 UI 示範導覽（功能齊備度檢查用）

> 目的：唔使睇碼、唔使等後端，都可以逐項檢查「功能係咪齊備」。
> 呢一版係 **UI 先行示範**：純靜態、零依賴、全部資料係示範旅 MOCK（住你部機嘅 localStorage），
> **唔會連任何後端**，亦**唔會**假裝寫入成功。

- 版本：`v0.1.0-ui`（示範模式）
- 對應計劃書：`docs/旅系統建構計劃.md`
- 真後端（旅 GAS ＋ /api/proxy）**未實作**；UI 上所有「真模式會點」都寫明係示範。

## 1. 一分鐘路線（想快睇全貌）

1. 開 `index.html` → 旅閘（揀旅、伺服器登記狀態、診斷、新旅部署申請）

3. 儀表板 → 左邊導航逐個撳（順序＝施工分期 P0 → P3）

## 3. 一定要睇嘅「死規矩」示範（呢啲最易做錯）

1. **單一寫入掣**：改任何嘢只會變「N 項未寫入」，要撳頂部「儲存到後端」；收據一定要有 `confirmed:true`（寫完讀返自證），冇就當失敗。
2. **誠實失敗**：接駁燈三色（綠＝接駁好＋已閂本地登入／黃＝已登記未閂／紅＝未接駁）；後端實況如實報行數、壞表、後端版本。
3. **金鑰永不落地**：QR／連結、URL、前端碼永不見 apikey；變數 A／B／C／D 只喺 Vercel env 同 GAS ScriptProperties。
4. **冇 callback／冇定時器**：系統 →「自動化」寫明每項工作喺平台側（GitHub Actions／Drive／排程）執行。
5. **成員帳號住支部**：旅只做導流（旅閘「我係成員」→ 揀支部 → 轉去該團成員入口）；旅唔會、亦唔可以代驗成員密碼。
6. **未登記不得加導航**：導航由 `assets/js/lib/registry.js` 自動生成（最多兩層），模組開關喺系統 →「模組開關」。
7. **家長頁係旅專有**：支部系統冇家長頁（深資自務自治），所以「我的子女」只喺旅出現。
